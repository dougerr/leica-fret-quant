# 论文版式统计图规范

以下常量从论文 PDF 逐像素采样确认，可直接复用。
对应脚本：`scripts/plot_cells_thesis_style.py`。

## 统计图（论文常见样式）

| 元素 | 规范 |
|---|---|
| 散点（主统计形式） | 空心圆：白填充、彩描边（lw≈0.9, s≈26），均匀抖动 ±0.22 形成蜂窝密堆 |
| 红（光照/实验） | `#E94A50`（RGB 233,74,80） |
| 蓝（黑暗/对照） | `#3938D5`（RGB 57,56,213） |
| mean±SD 线 | 灰 `#4D4D4D`：横线=mean（±0.28 半宽），竖线=SD，SD 端短横（±0.16 半宽） |
| 柱状图（辅助形式） | 灰填充 `#96969B`、黑边框、黑误差线（capsize=4）；柱顶黑实心点=各重复值（n=3） |
| 坐标轴 | 仅左+下轴，无顶/右轴，无网格，黑色 |
| 字体 | Times New Roman（serif），图内英文 |
| Y 轴标签 | "Ratio 610 nm/450 nm" / "FRETN (610 nm/450 nm)" |
| Y 上限 | **98 分位自适应** `max(0.30, q98*1.15)`，防高离群点压缩主体 |

脚本面板组成：左 = FOV 级灰柱+黑点，右 = 细胞级红/蓝空心圆散点+mean±SD 灰线。
