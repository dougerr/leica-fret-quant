# FRET 定量指标口径与避坑清单

本文件补充 SKILL.md 未展开的领域细节，供需要时查阅。

## 三个指标的数学定义与适用性

设供体(D=ch03)、敏化发射(S=ch00)、受体(A=ch01)三通道，`mask` 为供体 Otsu 前景（细胞区），`fg` 表示 mask 内均值扣除 mask 外背景后的净强度。

| 指标 | 公式 | 特点 | 适用 |
|---|---|---|---|
| `ratio_raw` | mean(S)/mean(D) | 整视野不扣背景，= Trae alpha=0「NFRET」口径 | 供体/背景稳定的情况下作对照 |
| `ratio_gs` | S_fg / D_fg | 扣背景，但只对供体归一化，对供体浓度/漂白敏感 | 背景不均时的中间口径 |
| `FRETN` ★ | S_fg / sqrt(D_fg × A_fg) | Xia 归一化，对供体+受体做几何平均，浓度无关 | **推荐主指标** |

选择依据（实测教训）：`ratio_raw`/`ratio_gs` 只对供体归一化，
供体光漂白或表达量差异会直接扭曲光暗比。典型伪影：光照组供体因光漂白
净信号大幅下降（实测可降约 50%），`ratio_raw` 出现约 2× 的假性升高；
改用 `FRETN` 后该伪影消失（回落至 ≈1.0×）。

## 通道映射（LAS X 0-based 导出实测确认）

- ch00 = FRET 敏化发射（405nm 激发，受体发射窗口）
- ch01 = 受体直接激发（受体表达量）
- ch02 = 明场/透射光（弃用，均值≈182，切勿当 FRET）
- ch03 = 供体 BFP（405nm 激发 / 450nm 发射）

## 命名约定与条件解析

### 布局 A：平铺

所有视野所有通道混在同一文件夹，文件名 `<前缀>_Position<NNN>_ch<CC>.tif`：
`S1-D-E_Position001_ch00.tif`、`S3-P_Position005_ch03.tif`。
前缀按 `-` 分段：第一段=基因型；`-D` 独立成段=黑暗组（否则光照）；`-E`=实验组、`-P`=阳性对照。

### 布局 B：子目录

目录名最后一个 `_` 之后为 `基因型-光照-类型-视野`，例如：
`20250101-FRET-S1_G1-D-E-1` → genotype=G1, dark, type=E, position=1。

- `-D` 段出现 = 黑暗组；无 = 光照组
- `-E` 段 = 实验组；`-P` 段 = 阳性对照
- 最后一段纯数字 = 视野号（-1 到 -5）；第一段 = 基因型

局限：基因型不得含孤立字母 D/E/P（会与光照/类型段混淆）。
如需不同命名，改 `analyze_fret.py` 的 `parse_sample()` 或 `analyze_fret_flat.py` / `per_fov_imaging.py` 的 `parse_condition()`。

## QC 规则

- 剔除 `D_fg < 20` 的视野（供体净信号过低，敏化发射信噪比≈1，FRET 不可靠）。
- 典型情况：部分视野供体前景不足（`D_fg` 落在 4–19 区间），多属转染效率或批次差异。
- 需要完整数据时用 `--no-qc`（绘图）或保留 `fret_fov.csv` 原始行（分析脚本已含全部样本）。

## 避坑清单（历史踩坑复盘）

1. **8-bit 而非 16-bit**：徕卡导出为 8-bit LZW 压缩 TIF，需 `imagecodecs` 支持读取。
2. **通道识别**：不能靠文件名关键词自动猜（样本名含 "FRET" 会污染所有通道），必须按 `_ch00/_ch03` 后缀严格匹配。
3. **明场通道**：ch02 均值≈182，若误当 FRET 会让 ratio 虚高到 0.8–0.9。
4. **指标口径**：论文/流式/Trae 用「整视野平均荧光之比」而非「逐像素比值中位数」，前者量级≈0.2–0.3，后者虚高。
5. **供体漂白伪影**：光照组供体减弱会让供体归一化指标假性升高，必须用 FRETN 消除。
6. **中文字体**：matplotlib 图内尽量用英文标签，或显式指定 Microsoft YaHei，避免中文乱码。

## 每视野伪彩成像图（per_fov_imaging.py，强度加权版）

**输出结构**：`per_fov/<prefix>/` 每夹 6 个 TIF——
`_ch00/_ch01/_ch03.tif`（原始灰度复制）+ `_Acceptor.tif`（红）+ `_Donor.tif`（蓝）+ `_FRETRatio.tif`（渐变）。
默认整包 `per_fov.zip`。伪彩为**单页 RGB TIFF**（photometric='rgb'、uint8、deflate level 6），
与 LAS X 多通道 TIF 同款，Fiji 直接打开。

**命名兼容**（两种批次都支持，自动识别）：
- A) `<批次前缀>_<基因型>-<D?>-<E|P>-<视野号>_chCC.tif`
- B) `<基因型>-<D?>-<E|P>_Position<NNN>_chCC.tif`

**通道上色（与原始灰度逐像素对应）**：
- 输入先 σ=1.0 高斯平滑；bg = 各通道 5% 分位数
- Acceptor = view_norm(A_s − bgA) → 乘红 (1.0, 0.18, 0.18)
- Donor = view_norm(D_s − bgD) → 乘蓝 (0.28, 0.60, 1.0)
- `view_norm` = 0.5–99.8 分位数稳健拉伸，clip 到 [0,1]。跨视野绝对亮度不可比（各自归一化）。

**FRET Ratio 观感算法（已定稿，勿随意改）**：

    Ratio 图 = 基准通道灰度（明度/纹理） × FRET 色阶颜色（色相） × brightness

- **核心：Ratio 图与基准通道伪彩图逐像素共用同一张灰度图**——同一 `view_norm` 输出、
  同一 σ、同一 gamma。因此轮廓、细胞内部纹理、亮度层次和 Acceptor/Donor 伪彩图**完全一样**，
  **只有颜色**反映 FRET 比率。验收标准：Ratio 图应与基准通道伪彩图在轮廓、纹理、
  亮度层次上完全一致，仅色调不同。
- **基准通道默认 donor**（`--base-channel acceptor` 可切）：受体亮/供体弱的细胞 D≈背景时
  S/D 被除法放大出假高值（实测虚高至 0.76，正常细胞仅 0.07），以 donor 作明度可自动压暗
  这类不可信区域；若需与受体行完全同貌选 acceptor。
- ratio = S_s / max(D_s, 1.0)（**原始 S/D，LAS X 口径，不做背景扣除**——与论文图呈像口径一致）
- 绝对标尺 **0–0.6**（论文常用标尺，**不随视野自适应**）
- `--brightness` 默认 **0.65**（实测 0.8 偏亮）
- 渐变 colormap 锚点（从论文图采样）：
  0.00 青(11,226,251) → 0.25 (10,249,210) → 0.38 (11,249,113) → 0.50 绿(8,249,10)
  → 0.62 (55,249,9) → 0.75 (157,251,13) → 0.88 黄(250,192,12) → 1.00 橙红(245,112,5)
- 显示 ratio ≠ 定量主指标 FRETN：成像图仅作观感呈现，**定量结论以 CSV 为准，不要从伪彩图读数**。

**关键教训（v1–v4 全部踩过，勿重蹈）**：
- ❌ 硬掩膜（受体 Otsu / 供体阈值）会把细胞边缘切掉 → 形态残缺。
- ❌ 阈值化权重 `clip((d-lo)/soft)**g` 或 `d**gamma` 充当明度 → 细胞内部纹理被压平成
  单色色块，看起来"失真"。**必须用通道原始灰度作明度**（`--w-gamma 1.0`）。
- ❌ 在一张图里拼多种呈现（ratio+灰度+多行分组大图）不可取；应改为**按视野分夹、
  ratio 与灰度分开存放**的打包形式。

**其他参数**：`--sigma`（默认 1.0）、`--disp-gamma`（默认 1.0）、`--w-gamma`（默认 1.0，
即原样复制该通道质感）、`--preview png`（可选预览图，非交付物）。**改动前必须留回滚点。**

**显示名替换**：`--rename S3=S1` 只改 TIFF description 标注，不改文件名与数据。

**历史口径（已废弃，仅备查回滚）**：更早一版用「受体通道 Otsu + fill_holes 掩膜 → 仅
`D_fg > 0.2·p95` 像素算 S_fg/D_fg → σ=2 → nan 置黑」，配色锚点为
cyan(76,229,232)→(76,233,149)→(108,232,68)→(201,237,77)→(229,173,77)→红(219,68,40)。
因细胞形态被掩膜切碎、观感差被替换。若需回滚，从 git/备份取旧版本。

## 伪彩成像踩坑（历史复盘）

1. **TIFF `description=` 必须纯 ASCII**：中文描述触发 tifffile "must be 7-bit ASCII" 报错。
2. **colorbar 保存被裁**（PNG 面板时代）：`fig.colorbar(im, ax=ax)` + `bbox_inches='tight'`
   会裁掉手动 `add_axes` 的 colorbar——改用 `fraction=0.046, pad=0.05`。
   当前 TIF 版无 colorbar/标注轴，纯像素。
3. **输出格式演进**：带标注 PNG → 多页 RGB TIF → 拆分单页三张（当前定稿）；
   定量柱状图用 PDF，通道上色图维持 TIF。

## 结果解读速查

以 `fret_dark_vs_light.csv` 的 FRETN 行为准：

| fold change | p 值 | 判读 |
|---|---|---|
| ≈1.0 | >0.05 | 光照与黑暗无差异 → 该构建无光控响应 |
| >1.2 或 <0.85 | <0.05 | 存在光控响应，方向看 fold（>1 光照高、<1 光照低） |
| 偏离 1 但 p 在 0.05–0.10 | — | 仅趋势，需增补重复视野后再判 |

判读必须结合对照组：至少包含一个**序列阴性对照**与一个**已知不响应光控的对照构建**，
两者均应为 ≈1.0 且 ns，才能确认光开关本身工作、阳性结果不是系统偏差。
